Known Limitations / Findings

DABs v0.270.0 / TF provider v1.88.0 limitation: Resource types resources.queries, resources.alerts, and resources.genie_spaces are not managed by the Databricks Terraform provider in this version — they emit "unknown field" warnings and are not instantiated as workspace objects. Alert and Genie bundles sync YAML files only. Manual workspace creation is required for the alert query/object and Genie space. This is a tooling constraint, not a data or SQL issue. Escalation to devops-engineer for DABs version upgrade or manual workspace creation is recommended.
lvdash.json catalog hardcoding: Dashboard JSON files use dev. prefix (e.g., dev.g_network.*) instead of ${var.catalog}. This is correct for the DEV deploy but not portable. lvdash format does not support variable interpolation natively — this is acceptable for now; multi-env portability requires environment-specific file generation.
